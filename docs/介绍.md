# Catagorize for Windows

**特定文件夹整理工具：体检 / 规则整理 / 指纹去重 / 全文检索**

文件**原地不动**，工具围着文件转。受管目录随时脱离本软件照常使用，
不导入、不复制、零锁定。

---

## 这是什么

Catagorize 是一个 Windows 桌面工具，用来**整理你指定的文件夹**，而不是替你把文件收进另一个"资料库"。

传统资料库工具（如 DropDesk）把文件复制进自己的库，文件脱离原工作位置、产生副本、被格式锁定。Catagorize 反着来：

- **文件系统即数据库**：整理 = 在目录内移动文件，目录本身就是成果
- **索引与配置全部在用户配置目录**（`platformdirs`），受管目录保持干净
- **永不删除**：只有「移动」和「移入隔离区」两种动作，隔离也是移动
- **先预览后执行**：所有整理先出 dry-run 计划，冲突在计划期就暴露
- **一键撤销**：每个动作先记日志再动手，逆序回滚

## 两种画像模式

| 模式 | 适用 | 行为 |
|---|---|---|
| `flow` 流入型 | 下载目录、桌面 | 规则引擎 + 目录监听，新文件落盘自动归类（防抖 2 秒） |
| `archive` 存量型 | 项目资料库 | 体检报告 + 内容级去重 + 全文检索 |

## 功能一览

| 页面 | 功能 |
|---|---|
| 总览 | 受管目录统计卡片、系统时钟（精确到秒，含节气）、空间拼图画布（文件 = 矩形块，越大越深）、数据与缓存、关于、更新检查 |
| 文件夹 | 受管目录（画像）管理：添加 / 删除 / 切换模式 / 打开所在位置 |
| 体检 | 只读扫描：类型分布、体积 Top、重复组、垃圾文件；dry-run 计划 + 执行 + 撤销 |
| 检索 | 文件名 / 内容全文检索（SQLite FTS5） |
| 导出 | 目录树导出为 PowerShell `tree` 风格文本（txt / Markdown 可选） |
| 日志 | 实时操作日志（启动、扫描、执行、更新检查等），按级别着色，可清空 |
| 设置 | 主题（跟随系统 / 亮 / 暗）、语言（简体中文 / English，默认跟随系统）、更新检查源、恢复默认、关于 |

## 快速上手

1. 启动后进入「文件夹」页，添加要整理的目录，选择模式：
   - **流入型**：适合下载目录——给规则，新文件自动归类
   - **存量型**：适合已有大量文件的资料库——先做体检，再按报告整理
2. 「体检」页扫描，查看类型分布、体积占用、重复文件
3. 生成计划（dry-run，只读），确认无误后执行；后悔了可以**撤销**
4. 「检索」页随时按文件名或内容找回任何文件

## 卸载

标准卸载即可（设置 → 应用 → 卸载，或安装目录 `unins000.exe`）。
卸载只移除程序本身；**索引与配置保留在用户配置目录**，如需彻底清除可手动删除 `%LOCALAPPDATA%\Catagorize`。

## 隐私

所有数据处理均在本地完成。唯一联网行为是更新检查（访问 GitHub 公开发布页），不收集、不上传任何个人数据。

## 系统要求

- Windows 10 1809（17763）及以上，64 位
- 安装包约 40 MB（含 Python 运行时，无需另装）

## 便携模式

在 exe 旁放置 `portable.flag`，数据写入程序目录下的 `CatagorizeData/` 而非用户配置目录。
